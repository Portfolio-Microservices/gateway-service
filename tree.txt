For redis open docker : then : docker version
						then : docker run -d --name redis -p 6379:6379 redis:7
Verify Redis is running : docker ps
You can even enter the container: docker exec -it redis redis-cli
Then:  PING, Response: PONG

Check rate limiting call this using powershell :
1..20 | ForEach-Object {
    try {
        $r = Invoke-WebRequest http://localhost:8080/api/v1/projects -UseBasicParsing
        Write-Host $r.StatusCode
    }
    catch {
        Write-Host $_.Exception.Response.StatusCode.value__
    }
}
